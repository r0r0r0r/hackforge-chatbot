## 🌟 Overview

**HackForge** is an advanced AI intelligence hub designed for developers, researchers, and power users who want to query, compare, and benchmark multiple state-of-the-art AI models simultaneously in a unified glassmorphic cyber environment.

Whether comparing reasoning outputs between **Claude 3.5 Sonnet**, **GPT-4o**, **Gemini 1.5 Pro**, **DeepSeek-V3**, or running private on-device local models via **Ollama**, HackForge delivers instantaneous multi-bot responses with rich syntax highlighting, performance latency telemetry, and customizable model arenas.

---

## ✨ Key Features

- **⚔️ Multi-Model Arena & Split Matrix**:
  - Run side-by-side or 4-quadrant split views comparing different model outputs in real time.
  - Switch smoothly between **Single Model View**, **Dual Comparison**, and **Multi-Arena Matrix**.

- **🧠 Universal Model Integrations**:
  - **OpenAI**: GPT-4o, GPT-4o-mini, o1-preview.
  - **Anthropic**: Claude 3.5 Sonnet, Claude 3 Opus.
  - **Google**: Gemini 1.5 Pro, Gemini 1.5 Flash.
  - **DeepSeek**: DeepSeek V3, DeepSeek R1 Reasoning.
  - **xAI**: Grok 2, Grok Vision.
  - **Local LLMs**: Direct bridge to local **Ollama** (`http://localhost:11434`) running Llama 3, Mistral, Qwen, or DeepSeek.

- **🎨 Cyberpunk Glassmorphism UI**:
  - Ambient glowing gradient mesh canvas with animated SVG topographic flow lines.
  - Clean typography powered by Outfit, Space Grotesk, Plus Jakarta Sans, and JetBrains Mono.
  - Micro-animations, responsive layout, and adaptive dark mode.

- **📊 Real-Time Benchmark Telemetry**:
  - Track response latency (ms), token velocity, and consensus agreement scores.
  - One-click copy, Markdown formatting, code syntax highlighting, and chat export options.

- **📁 Conversation Management & History**:
  - Multi-thread chat history with auto-titling, search, pinned topics, and local persistence.
  - Zero cloud lock-in: All chat threads and API configurations remain securely in your local browser storage.

## 🚀 Quick Start

### Option 1: Instant Web Access (No Install)
Simply open the hosted application:
👉 **[https://r0r0r0r.github.io/hackforge-chatbot/](https://r0r0r0r.github.io/hackforge-chatbot/)**

---

### Option 2: Run Locally on Your Machine

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/r0r0r0r/hackforge-chatbot.git
   cd hackforge-chatbot
   ```

2. **Launch with any local HTTP server**:
   - **Using Python**:
     ```bash
     python -m http.server 5500
     ```
   - **Using Node (Vite)**:
     ```bash
     npm install
     npm run dev
     ```
   - **Using PowerShell (Windows native)**:
     ```powershell
     powershell -File server.ps1
     ```

3. Open **`http://localhost:5500`** in your browser.

## 🔒 Privacy & Security

- **Client-Side First**: Your prompts and chat history stay in your browser's `localStorage`.
- **Direct API Mode**: API keys entered into the settings modal communicate directly with AI endpoints and are never routed through intermediary servers.
